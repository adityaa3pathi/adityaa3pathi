## 🚀 What I've Built

### 🏥 Production Agentic AI — DocNow

Built and deployed a production agentic system serving **2,500+ healthcare users across 50+ cities**.

**Architecture:**

`Planner → Retrieval → Tool Calling → Verifier → Human Escalation`

**Key work:**

- Built LangGraph-based agentic workflows
- Hybrid **BM25 + pgvector** retrieval with reranking
- Retrieval across **1,100+ tests/packages**
- Redis-backed memory and context management
- Structured outputs and tool/function calling
- Grounded abstention to prevent hallucinated confirmations
- 80-query automated evaluation framework
- CI evaluation gates for every deployment
- Langfuse tracing, prompt versioning & production monitoring
- Improved context precision **55% → 82%**
- Reduced confident-wrong responses **9% → 2%**
- Delivered **147+ production APIs**

### 📧 AI Email Assistant

An AI-powered email SaaS combining RAG, fine-tuned models and autonomous agents.

**Highlights:**

- Hybrid RAG using **BM25 + pgvector**
- HNSW vector indexing and cross-encoder reranking
- Sub-200ms semantic search across **1,000+ emails/account**
- Fine-tuned **Mistral-7B using QLoRA**
- **92% classification accuracy**
- **4× lower inference cost** compared with prompted Gemini
- Served models using **vLLM**
- Agentic workflows with structured tool calling
- MCP server for email search, calendar lookup & drafting
- Kubernetes deployment with autoscaling
